# Provenance: where every number in this repository comes from

Generated by `scripts/check_provenance.py --write-doc` from
`taxiout.provenance`. Every count below is summed from those manifests
rather than written down, and check 10 of that script rebuilds this file
and fails if the committed copy differs, so an entry added to the register
without regenerating this document does not get committed.

The standing rule: every number reaching a report, a note or the paper is
computed by the run that prints it, quoted from a named source with that
source beside it, or marked an estimate with an instrument and an owner.
There is no fourth kind. This file is how that becomes checkable rather
than conventional.

## The four states

Every number in a covered surface is in exactly one of four states, and
the gate's job is to prove there is no fifth.

1. **Generated** by the run that prints it. Needs no entry.
2. **Checked** against a named source, so drift fails a gate.
3. **Registered** with a one-line basis: quoted measurements, chosen
   thresholds, frozen records.
4. **Exempt**, on an explicit list with a reason: mechanism and definition.

mean writing a plausible reason after the fact for a threshold nobody
argued, which is undetectable afterwards and is precisely the failure this
register exists to prevent. Check 3 prints the count so it cannot drift in
either direction without somebody seeing it.

## What a report declares it was generated from

**13** generators write a footer naming every
path the run read, with a sha256 each; check 8 recomputes them and calls
the report verified, stale or unverifiable. The rule for who carries one
is the Makefile's own measured time: under five minutes and the generator
writes a footer.

**2** reports carry none, and are listed here
rather than skipped: check 8 fails on a report with no footer that is on
no list, so the remainder is a decision and not an oversight.

## What a report quotes from another report

Check 11 reads every citation of a report by filename and requires every
decimal figure in the citation's own sentence to appear in the cited file.
The scope is the sentence: a paragraph drags in figures that belong to
other sentences, and a checker that flags what nobody claimed is a checker
that gets turned off.

**6** figures are
exempt, each with a reason, and check 11 fails on an exemption it cannot
reach as well as on a figure it cannot find.

## Authored artifacts

**`src/taxiout/synthetic.py`** -- a fictional airfield where every distance, turn and repair is hand-derived, with worked traffic in the challenge's own schema so the pipeline runs end to end without the challenge data. Its numeric constants ARE the field's definition, which is why the module is registered once here rather than constant by constant: there is no provenance question to answer about the coordinates of an invented stand.

The condition that makes it safe: **no generator of a model figure imports it**. Check 4 proves
it against 10 named generators rather
than this record claiming it.

## What a rebuild of an external input is pinned to

**1** external input(s) carry a pin. A pin is a claim
about what a rebuild would return. Exercising one costs the network and a
server willing to answer, so what is written here is how the pin is
applied, how a rebuild proves it was, and what would make it fail.

**the OSM movement-area geometry for the eleven airports, under `data/raw/*.json.gz`**

Rebuilt by `python scripts/fetch_osm.py --pin-from-register --force`, which pins each airport's Overpass query to its own entry in `OSM_PINS`.

Recoverable per airport, and only per airport, and from `OSM_PINS` rather than from the cache. The eleven entries carry **seven** distinct stamps spanning 2026-09-01T13:23:05Z to 13:32:15Z, because the fetch was sequential and unpinned and each airport was answered from whatever state its instance had ingested when it was served; one `--date` would pin eight of the eleven to a state their matrices were not built from. **The cache cannot carry them**: every answer is stamped with the answering instance's own current database state and never with the pin, so a pinned rebuild re-stamps each file with the rebuild day. The mode that read the pins from the cache, `--pin-from-cache`, would have worked exactly once and then pinned every airport to that day with no error, and it now refuses.

- attic retention is not guaranteed. An instance may decline a query at a date this old, and one that declines is a failure to report. The mode refuses to fetch an airport the register has no pin for, because **a silently unpinned fetch is a stop**: it would replace an answer whose OSM state is recorded with one whose is not.
- **nothing in an answer's header proves the pin was applied.** The proof is the elements: `--compare FETCHED REFERENCE` matches each airport's parsed elements on type and id against the cache the matrices were built from and compares every field, and the matrices built from them are compared after that. Not the payload bytes, which differ in the header between any two answers.
- an airport unchanged since its pin answers the same pinned or not, so a match alone does not show the pin at work. The control does: `--control-date` asks the instance that answered for one airport at a date whose answer is known to differ, and reports whether it does. LIRF at 2020-01-01T00:00:00Z differs, 355 elements against 494, measured on overpass-api.de on 25 September 2026.
- the client falls back to two other mirrors when the first fails, and neither has been asked an attic query. The fetch record names the mirror that answered each airport, and `--compare` prints it.

### The OSM pins, one per airport

**11** airports at
**7** distinct moments, in
`taxiout.provenance.OSM_PINS`, which is what `--pin-from-register` reads.
The basis, the same for every entry: each is the `osm3s.timestamp_osm_base` of that airport's cached Overpass answer, `data/raw/<ICAO>.json.gz`, which is the database state the Overpass instance that served it had ingested when it answered, on 1 September 2026. The eleven were fetched one after another and unpinned, so the database moved under the fetch and eleven answers carry seven moments rather than one. Read from the cache files on 25 September 2026, and the same eleven values Block 09e read from them on 22 September. **The cache header cannot be the source of truth, because a rebuild overwrites it.** Overpass stamps every answer with the answering instance's current database state and never with the `[date:]` pin, which Block 09h measured on three answers carrying a 2026 pin, a 2020 pin and none, so a pinned rebuild writes each file stamped with the day of the rebuild. And `data/raw/` is gitignored, so a clean checkout has no cache and would have no pins. Recorded here, they survive both.

## What this does not reach

Stated so its silence is not read as a pass.

| surface | treatment |
| --- | --- |
| module-level numeric assignments in `src/` and `scripts/` | covered by `CONSTANTS`, one entry each, and check 1 fails on any the scanner finds and the register does not carry |
| numeric defaults in function signatures | NOT covered. The scanner counts them and the census prints the count, but they are parameters of a call and not constants of a module, and every one that matters is bound to a module constant at the call site. Stated here so the silence is not read as a pass |
| `src/taxiout/provenance.py` | NOT covered, and it cannot be: its aggregate assignments hold every registered literal in the repository, so an entry for them would be a copy of the register inside itself and would drift whenever any other entry changed. Its own prose figures are the bases, each of which names its source, and check 7 excludes it for that reason |
| `scripts/check_provenance.py` | its `REPO` is registered like every other script's; its prose figures are the exemption table's own data, which is a list of figures by construction, so check 7 excludes it. It writes no report |
| which generators check 9 sees | those whose output path carries an `.md` string literal. Two build a dated filename with a format field -- `scripts/report_submission.py` and `scripts/preregistered.py` -- and are outside it. Both write a frozen dated record, which check 5 covers instead |
| `src/taxiout/synthetic.py` | covered once by `AUTHORED_ARTIFACTS` rather than constant by constant, with the condition that makes it safe proved by check 4 |
| decimal figures in generator prose strings | covered by check 7: each is computed from the data or registered as deliberate prose |
| decimal figures in code comments | NOT covered by an automated check. A comment is not read by any run and cannot reach a report, so a stale figure in one misleads a reader of the source and nothing else. The census counts them |
| `docs/` and `README.md` | the two frozen documents are covered by check 5, which is an immutability digest and not a currency check. `docs/paper.md` is Block 10's and is on the pending list; the rest carries no model figure |
| cross-report citation | covered by check 11, scoped to the citation's own sentence and to decimal figures. Bare integers are out: a report says *the three airports* and *5 folds* in words a gate cannot tell from a measurement. A frozen dated record is out as a citing document, because its figures were true on its date and the file it cites has moved since, which is what makes it a record; check 5 holds it to a digest instead |
| `docs/paper.md` as a citing document | NOT covered by check 11, and deliberately: it is stale by its own pending entry, so running the check over it would print a wall of findings that are all one fact. Block 10 builds the paper's own checker as part of the figure pass |
| the line numbers a basis cites | covered by check 12. A basis that names a line is a citation and drifts the moment anything above it is edited: the commit that created this register edited two of the generators it registers and left sixteen of its own citations pointing at blank lines and unrelated code. The cost is that an edit above a cited constant now fails the gate until the citation is moved, which is the intended trade -- a citation that fails loudly beats one that drifts quietly |
| a line citation into another file | checked only for existing and for not being blank, which is all a line number in prose can be checked for. Where the cited file is regenerable the citation is pointed at a frozen dated record instead, which cannot move under it |
| the notes and prompts outside the repository | unreachable by any gate here. The discipline there is that a number is never invented to stand in for one not yet measured |
