# Provenance: where every number in this repository comes from

Generated by `scripts/check_provenance.py --write-doc` from
`taxiout.provenance`. Every count below is summed from those manifests
rather than written down, and check 10 of that script rebuilds this file
and fails if the committed copy differs, so an entry added to the register
without regenerating this document does not get committed.

The standing rule: every number reaching a report, a note or the paper is
computed by the run that prints it, quoted from a named source with that
source beside it, or marked an estimate with an instrument and an owner.
There is no fourth kind. This file is how that becomes checkable rather
than conventional.

## The four states

Every number in a covered surface is in exactly one of four states, and
the gate's job is to prove there is no fifth.

1. **Generated** by the run that prints it. Needs no entry.
2. **Checked** against a named source, so drift fails a gate.
3. **Registered** with a one-line basis: quoted measurements, chosen
   thresholds, frozen records.
4. **Exempt**, on an explicit list with a reason: mechanism and definition.

## Authored artifacts

**`src/taxiout/synthetic.py`** -- a fictional airfield where every distance, turn and repair is hand-derived, with worked traffic in the challenge's own schema so the pipeline runs end to end without the challenge data. Its numeric constants ARE the field's definition, which is why the module is registered once here rather than constant by constant: there is no provenance question to answer about the coordinates of an invented stand.

The condition that makes it safe: **no generator of a model figure imports it**. Check 4 proves
it against 10 named generators rather
than this record claiming it.

## Frozen documents

the opposite gate from every other file here: the risk is not that they go
stale, it is that somebody edits them. A currency check over one would
demand destroying the record.

## What this does not reach

Stated so its silence is not read as a pass.

| surface | treatment |
| --- | --- |
| module-level numeric assignments in `src/` and `scripts/` | covered by `CONSTANTS`, one entry each, and check 1 fails on any the scanner finds and the register does not carry |
| numeric defaults in function signatures | NOT covered. The scanner counts them and the census prints the count, but they are parameters of a call and not constants of a module, and every one that matters is bound to a module constant at the call site. Stated here so the silence is not read as a pass |
| `src/taxiout/provenance.py` | NOT covered, and it cannot be: its aggregate assignments hold every registered literal in the repository, so an entry for them would be a copy of the register inside itself and would drift whenever any other entry changed. Its own prose figures are the bases, each of which names its source, and check 7 excludes it for that reason |
| `scripts/check_provenance.py` | its `REPO` is registered like every other script's; its prose figures are the exemption table's own data, which is a list of figures by construction, so check 7 excludes it. It writes no report |
| which generators check 9 sees | those whose output path carries an `.md` string literal. Two build a dated filename with a format field -- `scripts/report_submission.py` and `scripts/preregistered.py` -- and are outside it. Both write a frozen dated record, which check 5 covers instead |
| `src/taxiout/synthetic.py` | covered once by `AUTHORED_ARTIFACTS` rather than constant by constant, with the condition that makes it safe proved by check 4 |
| decimal figures in generator prose strings | covered by check 7: each is computed from the data or registered as deliberate prose |
| decimal figures in code comments | NOT covered by an automated check. A comment is not read by any run and cannot reach a report, so a stale figure in one misleads a reader of the source and nothing else. The census counts them |
| `docs/` and `README.md` | the two frozen documents are covered by check 5, which is an immutability digest and not a currency check. `docs/paper.md` is Block 10's and is on the pending list; the rest carries no model figure |
| cross-report citation | NOT covered. On the pending list, owned by `code_09e` |
| the notes and prompts outside the repository | unreachable by any gate here. The discipline there is that a number is never invented to stand in for one not yet measured |
